# Summoner companions · Alpha 0.30.0

Each of `bat`, `imp`, `spirit`, `giant` contains `atlas.png`, `atlas.json` and a small `preview.png`. Each full atlas has 60 painted frames: four six-frame motion rows, four six-frame attack rows, one shared six-frame summon strip and one shared six-frame dissolve strip. Motion includes actual changing wings, claws, cloth, ghost tails or stone segments. Left facings are separately drawn, not whole-sheet mirrors. Small familiars use 112px cells; the golem uses 160px cells, keeping all textures below 2048px on either side.

Bat: purple vampire familiar with articulated membrane wings and fangs. Imp: rust-red horned flying fire familiar. Spirit: hooded cyan/violet ghostfire familiar with spectral claws and no legs. Giant: heavy hovering basalt rune golem with stone fists and a suspended segmented rock core; its levitation is intentional. These creatures retain their established gameplay roles and collision radii.

`src/companion-animation.js` owns local simulation clocks and one-shot release on frame 2 of six. Attacks lock a target/point, check line of sight again on release, and retain the prior cooldowns and damage formulas. Pause/hitstop freeze clocks. The golem’s combat actor disappears at 3.8s; a separate non-combat visual effect plays the 0.48s dissolve.

`tools/pack-companions.cjs` requires offline Sharp. It finds transparent row gutters, isolates neighboring pose fragments, preserves nearby floating stones/flames, tightens UVs and packs alpha-paletted atlases. It derives hand/flame emission points from the actual release art, writes them to each manifest and generates `src/companion-emission.js`. The game does no per-frame pixel reads or image processing. `CompanionSpriteAtlas` loads only the selected familiar plus the golem when using the summoner, with asynchronous stale-selection guards; other classes retain zero full companion texture loads. Preview strips decode separately. Projectiles use the existing ground collision plane with a visual height offset.

Artwork used the built-in Imagegen tool, with the existing summoner sprite sheet as a style reference. Final prompt set: detailed dark fantasy pixel art and matching palette; six columns/four rows, front/right/back/left; six truly different flight/hover poses, then a separate six-pose attack sheet with anticipation, gather, release/contact at column 3, follow-through, recoil and recovery; separate six-column/two-row materialize/dissolve stages; exact creature identities listed above; generous gutters, full wings/fists/tails, transparent alpha, no text, labels, grid, floors or scenery. The transparent atlas packing removes non-character fragments at source cell boundaries. These new files replace the old code-drawn rectangular companion bodies in the renderer.

Validation: all 240 frames decoded and rendered in Chromium and WebKit, six distinct frames in every strip, valid UVs, unclipped bodies, release points intersect actual fire/cyan hand pixels, animated selection cards, each of the three selectable familiars in live runs, and keyboard/touch summoning. Unit checks cover one-shot release, bite healing/whiffs, aiming, cooldowns, expiry, pause/hitstop, regroup cancellation, blocked attacks and asynchronous stale loads.
